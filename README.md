# سیستم حضور و غیاب - Attendance System

یک اپلیکیشن موبایل تمام‌کاره برای مدیریت حضور و غیاب کارکنان و کسب و کارها.

## ویژگی‌های اصلی (برنامه‌ریزی شده)

- ✅ ثبت حضور/غیاب
- 📊 گزارش‌های تفصیلی
- 👥 مدیریت کاربران
- 🔔 اطلاع‌رسانی‌های خودکار
- 📍 تشخیص موقعیت مکانی
- 🎯 نقش‌های کاربری
- 📈 آمار و نمودارها
- 🌙 حالت تیره و روشن

## تکنولوژی

- **Frontend:** React Native / Expo
- **Backend:** Node.js + Express
- **Database:** Firebase / MongoDB
- **Authentication:** JWT

## نحوه راه‌اندازی

```bash
# Clone کردن
git clone https://github.com/TreXAli/Ali.git

# نصب وابستگی‌ها
npm install

# اجرای پروژه
npx expo start
```
